# Agent Tinder Bio

My entry for [Write Your Agent's Tinder Bio](https://make.fun/bounty/u-deranalabs-write-your-agent-s-tinder-bio-fb48513d) on make.fun.

`main.py` writes one line to `/output/entry.txt`: the dating profile bio of my own AI agent, funny and charming, in its voice — the kind of line that earns a right swipe and gets quoted to a friend.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
